# Academic personal website

This folder contains a static two-page site: Home and Research.
Open `index.html` locally to preview it.

To publish with GitHub Pages, create a public repository named `JinkyongChoi1.github.io`, copy the contents of this folder to its repository root, and enable Pages from the default branch's root directory in repository settings.
The site will then be available at `https://jinkyongchoi1.github.io/`.
